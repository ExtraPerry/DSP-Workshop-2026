# SkillSwap

Le site qui connecte les étudiants par leurs compétences.

## Description

Sur le campus, les étudiants regorgent de compétences variées (développement web, design, langues
étrangères, montage vidéo, comptabilité, sport, musique…) mais peinent souvent à trouver le bon
interlocuteur pour progresser ou transmettre leurs savoir-faire.
C'est dans ce constat qu'est née l'idée de SkillSwap : un site internet qui permet aux étudiants d'un
même établissement de s'échanger des compétences, de s'organiser en sessions d'apprentissage
entre pairs et de valoriser leurs expertises au sein d'un réseau de confiance.
La direction de l'établissement a validé le principe et souhaite accompagner le lancement de la
solution. Elle mandate votre équipe pour piloter ce projet de A à Z dans un cadre simulant les
conditions d'une agence digitale répondant à une commande client réelle.
Le projet démarre par un site internet conçu dès l'origine pour pouvoir évoluer vers une application
mobile dans une phase ultérieure. Cette contrainte d'évolutivité doit guider vos choix technologiques
dès maintenant.

## Périmètre fonctionnel de SkillSwap

Pour contextualiser vos productions, voici les fonctionnalités envisagées pour le site :

- Profil étudiant : liste de compétences, niveaux déclarés, disponibilités
- Système de matching : trouver un étudiant pour apprendre ou enseigner une compétence
- Gestion des sessions : planification d'ateliers, de cours rapides, de clubs thématiques
- Gamification : badges, points, défis entre utilisateurs, niveaux de progression
- Feed social : partage de réalisations, recommandations, feedbacks entre pairs

Le site devra être pensé dès sa conception pour permettre une évolution future vers une application
mobile. Cela implique des choix technologiques adaptés et une architecture découplée que vous
devrez anticiper et justifier dans vos livrables.
