# Template Next.js Website

A template Next.js website for myself to use as a base for any project I would like to start with.

## To use the project

To start a project make sure to add your own .env file.

- Run ```npm install``` to add all libraries and dependencies after pulling the project.
- Run ```npm run dev``` to start local project.
- Run ```npm run build``` to compile the project.

## Used node (npm) libraries

### Framework

- Next.js (React) (<https://nextjs.org/>)

### Utilities

- Tanstack Query (<https://tanstack.com/query/latest>)
- Zod (<https://zod.dev>)

### User Interface

- Next-Intl (<https://next-intl.dev/>)
- Shadcn (<https://ui.shadcn.com>)
- Lucide React (<https://lucide.dev/icons>)
- Tanstack Form (<https://tanstack.com/form/latest>)
